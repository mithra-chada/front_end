# Image Captioning Web App

This is a Streamlit web application that generates a caption for an uploaded image.

## Setup

1.  Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

2.  Download the pre-trained model files by running the setup script:
    ```bash
    ./setup.sh
    ```

## Usage

To run the application, use the following command:

```bash
streamlit run app.py
```
